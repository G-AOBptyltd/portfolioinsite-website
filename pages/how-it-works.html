Installation & Setup
Step 1: Installation

One-click installation

Installing PortfolioInSite is straightforward and requires no technical expertise. Navigate to the Atlassian Marketplace, search for PortfolioInSite, and click Install. Follow the permission grant flow to authorize PortfolioInSite to access your Jira data.

  • Find PortfolioInSite in the Atlassian Marketplace
  • Click "Get it now" and select your Jira instance
  • Review and approve the required permissions
  • Installation completes in seconds
  • No configuration files or coding needed

Project Discovery
Step 2: Project Connection

Automatic project discovery

Once installed, PortfolioInSite automatically scans your Jira instance and identifies all accessible projects and boards. Our intelligent discovery engine detects your existing portfolio structure, team assignments, and cross-project dependencies without requiring any manual configuration.

  • Map team assignments across projects

Common Questions

Frequently asked questions

Everything you need to know about getting started with PortfolioInSite.

How long does installation take?

Installation typically takes less than 2 minutes. You'll be guided through a simple wizard that handles marketplace authentication and permission granting. Once complete, PortfolioInSite begins discovering your projects immediately.

Do I need to configure each project individually?

No. PortfolioInSite automatically discovers all your projects. You don't need to manually register or configure individual projects. Our intelligent system recognizes your existing portfolio structure and begins aggregating data right away.

What permissions does PortfolioInSite need?

PortfolioInSite requires read access to your projects, issues, and user data to build dashboards and dependency maps. We follow Jira's permission model strictly and never request more access than necessary. All data stays within your Jira instance.

How are dependencies automatically detected?

Our dependency detection engine analyzes link types, custom fields, and issue relationships in your Jira instance. It identifies issue links (blocks, depends on, relates to) and custom dependency fields to build a comprehensive cross-project dependency graph automatically.

Can I customize what data is displayed?

Yes. PortfolioInSite provides extensive customization options. You can create multiple dashboard views, choose which metrics to display, apply filters, and customize report templates. Different stakeholders can see tailored views of the same data.

Is there any ongoing maintenance required?

PortfolioInSite is designed to require minimal maintenance. It automatically syncs with your Jira data in real time. You simply create dashboards and customize views as your portfolio needs evolve. We handle all infrastructure and updates.
